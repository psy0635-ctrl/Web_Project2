# MODE / EDIT — 실제 상품 정보 버전

기존 React 실습용 MODE / EDIT에 공식 상품 사진 주소와 공식 자료에서 확인한 상품 정보를 연결한 버전입니다. 실제 판매 서비스가 아니며 UNIQLO 및 신세계와 제휴하지 않습니다.

## 적용 순서

1. 기존 프로젝트의 `src/App.js`, `src/App.test.js`, `src/index.js`, `src/shopping-landing`을 백업합니다. Git 사용 중이면 `git status`도 확인합니다.
2. ZIP의 `src` 폴더 안 파일들을 기존 프로젝트의 같은 위치에 복사합니다. 기존 `fit-finder`, `fashion-home`, `13`, `14`, `index.css`, `reportWebVitals.js`, `setupTests.js`, package.json과 lockfile은 보존합니다. `FashionArtwork.js`는 더 이상 참조하지 않으며 삭제하지 않아도 됩니다.
3. 기존 package.json이 있는 폴더에서 `npm start`를 실행합니다(CRA 기준). 새 패키지 설치는 필요하지 않습니다. 기본 주소 또는 `#/shopping`에서 새 화면을 확인합니다. 기존 홈페이지는 `#/fashion-home`, FIT FINDER는 기존 주소 그대로입니다.
4. `npm test -- --watchAll=false`와 `npm run build`를 실행합니다(CRA 기준).

## 기능

- 라이트/다크 모드와 localStorage 유지
- 6개 실제 상품 카드, 카테고리, 카드/목록 전환
- 이미지 또는 상품명 클릭으로 별도 상세 화면 표시(같은 페이지 안에서 조건부 렌더링)
- 상세에서 상품번호, 소재, 대표 색상, 사이즈, 관리 방법, 참고가, 공식 링크 확인
- 목록 복귀 시 기존 필터 유지 및 해당 카드로 포커스 복귀
- 사진 로딩 실패 시 확인된 상세 이미지가 있는 상품은 대체 사진을 시도하고, 실패하면 안내 표시
- 사진은 외부 URL이므로 인터넷 연결이 필요하며 공식 서버에서 차단하거나 URL을 변경하면 표시되지 않을 수 있습니다.

## 출처 및 확인 범위 (2026-11-26 조사)

상품 데이터는 공식 페이지 검색 자료의 스냅샷을 바탕으로 요약했습니다. 실제 가격은 변경될 수 있으며 모든 가격은 참고가로 표시합니다. 사이즈는 재고가 아닌 공식 자료에 나열된 범위입니다. 스타일 팁 및 영문 제목은 학습용으로 작성한 설명입니다. 상품 사진의 권리는 해당 권리자에게 있으며, 공개 배포 시 사용 조건 및 허락 여부를 별도 확인하세요. 직접 다운로드해 재배포한 사진은 포함하지 않습니다.

## 검증

- TypeScript 파서 및 JSX 변환: JS 파일 7개 통과
- PostCSS 구문 및 선택자 범위: 통과
- 상품 수, ID 중복, 카테고리, 가격 포맷, URL 구조, 필수 정보 검사: 통과
- 기존 전체 React 프로젝트와 의존성이 제공되지 않아 npm build, Jest 및 브라우저 실제 동작은 미실행.
- 추가한 테스트는 테마, 필터, 상세/복귀, 이미지 오류를 검사하도록 작성했으며 학교 PC에서 실행해야 합니다.
- 브라우저에서 6개 사진 모두 표시되는지, 상세 링크가 정확한 상품/색상으로 이동하는지 확인하세요. 사진이 실패하면 해당 공식 상품 페이지의 실제 이미지 주소를 복사해 shoppingData.js의 image 값으로 교체하세요. 필요한 경우 직접 촬영했거나 사용 허가를 받은 사진을 프로젝트에 넣어 외부 연결 의존성을 줄일 수 있습니다.
